# Lista de contatos

Página simples para organizar uma lista de ligações. Você cola nomes e números, clica no número para copiar (sem o 55) e marca o contato como ligado.

## Como usar

Abra o `index.html` no navegador. Não precisa instalar nada.

- **+ Colar contatos**: cole a lista, um contato por linha. Ao colar, ele já adiciona.
- **Número**: clique para copiar sem o código do país.
- **Liguei**: marca como ligado. Clique de novo para desmarcar.
- **Ordenar A-Z** e **Apagar lista** ficam no mesmo painel.

Formatos aceitos:

```
Maria	11 98765-4321
Maria 11 98765-4321
(11) 98765-4321 Maria
11987654321
```

## Dados

A lista fica salva só no navegador (localStorage). Nada é enviado para servidor.
Por isso não coloque contatos reais dentro do repositório.

## Publicar no GitHub Pages

1. Suba os arquivos para um repositório.
2. Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`.
3. O site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
